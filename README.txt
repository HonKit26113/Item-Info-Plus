Changelog
Version 1.17
Released Oct 10, 2026

New Additions and Changes:
+ Compost Information!
 - Added a new compost icon to show the percentage chance of increasing the compost level of a composter.
 - This icon is shown on the item names of compostable items.

+ Wilderness Bound Support:
 - Added furnace fuel information for Poplar wood and its products.

+ Chaos Cubed Support:
 - Added duration information for the Bounce music disc.

+ Other Changes:
 - Moved the Item Info+ settings page to the How To Play screen. The new Ore UI settings page cannot be modified by resource packs.

Bug Fixes:
 - Armor Point and Durability information now shows for Copper Boots.
 - Furnace Fuel information now displays for Overworld wood shelves, Mangrove Propagule and Pale Oak Wood.

CHANGELOG
Version 1.10
Released January 12, 2023
The Changelog below may not be 100% identical to the one on MCPEDL. In that case, the MCPEDL version shall prevail.

New Supported Language:
 - Vietnamese (requires The Ty-el's Vietnamese Language Pack)

Changes and Additions:
 - A warning icon now appears in the item name of foods that give negative effects!
 - Added a new "Add-on Cross-compatibility" section in the Item Info+ screen in the game settings.
 - Added support for the "5" music disc.
 - Added support for the Swift Sneak enchantment.
 - Added support for the Ender Dragon and Wither Spawn Eggs, alongside a new icon for Bosses in their spawn eggs' item names.
 - Added support for the Allay and Warden Spawn Eggs.
 - Added support for the Camel Spawn Egg.
 - Added support for the Snow Golem and Iron Golem Spawn Eggs.
 - Added support for new items from the Beyond The Underground add-on.

Fixed Bugs:
 - The settings screen now works correctly in versions 1.19.40 and above.
 - There is no longer an extra space in the item name of Raw Chickens.
 - There is no longer an extra space in the item name of Apples in Finnish.
 - There is no longer an extra space in the item name of the Agent Spawn Egg in Traditional Chinese.

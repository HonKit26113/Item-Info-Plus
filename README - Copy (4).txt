Changelog
Version 1.14
Released May 2, 2024

New Additions:
+ 1.21 Support:
 - Added support for the Bogged Spawn Egg.
 - Added support for the Flow and Guster Banner Patterns.
 - Added support for the Mace.
 - Added support for the Density, Breach and Wind Burst enchantments.
 - Added a new mace icon to the Smite, Bane of Arthropods and Fire Aspect enchantments.
 - Added new icons for the Wind Charged, Weaving, Oozing and Infested effects to show their function.
 + Other Additions:
 - Added support for all types of Horse Armor.
 - Added missing stats for new items in the Beyond The Underground add-on in British English.

Fixed Bugs:
 - The additional attack damage values for the Sharpness enchantment are now shown in all languages.
 - The "s" in food consuming duration is now once again translated in all languages.
 - Fixed the translations of some items in Traditional Chinese to match Java Edition.
 - Fixed missing potion effect icons in the Minecraft Earth Style.
